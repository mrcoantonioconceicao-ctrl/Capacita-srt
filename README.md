## 🧠 Visão Geral

O **Capacita SRT Salomão** é uma plataforma educacional desenvolvida para formar cuidadores que atuam no "chão de fábrica" das moradias protegidas da RAPS. O objetivo principal é afastar o modelo asilar/manicomial de tutela e punição, promovendo a **reabilitação psicossocial, a autonomia do morador e o cuidado humanizado em liberdade**.

### 🎯 Principais Objetivos:
- **Resgate da Cidadania**: Garantir que a SRT seja reconhecida como um **LAR**, e não um mini-hospital.
- **Segurança Operacional**: Prevenir erros na administração de psicotrópicos, identificar reações extrapiramidais graves (acatisia, distonia, SNM) e padronizar a comunicação entre turnos.
- **Manejo de Crises sem Violência**: Capacitar para o uso da **Desescalada Verbal** (Método de Richmond / Projeto BETA), erradicando contenções físicas abusivas e punições.
- **Didática Aprofundada**: 5 módulos densos com 10 questões de fixação cada, estudos de caso reais e uma **Prova Final de 20 Questões Integradoras**.

## ⚖️ Fundamentação Legal e Normativa

Todo o conteúdo programático do curso foi estruturado com base nas legislações e diretrizes sanitárias federais e municipais vigentes no Brasil:

1. **Lei Federal nº 10.216/2001** *(Lei Antimanicomial)*: Proteção e direitos das pessoas portadoras de transtornos mentais e redirecionamento do modelo assistencial.
2. **Portaria GM/MS nº 106/2000**: Criação dos Serviços de Residência Terapêutica (SRTs) no âmbito do SUS.
3. **Portaria GM/MS nº 3.088/2011**: Instituição da **Rede de Atenção Psicossocial (RAPS)** para pessoas com sofrimento ou transtorno mental.
4. **Portaria GM/MS nº 2.840/2014**: Atualização do financiamento e funcionamento das SRTs Tipo I e Tipo II.
5. **RDC ANVISA nº 50/2002**: Normas para infraestrutura física e boas práticas higiênico-sanitárias em domicílios coletivos.
6. **Diretrizes da RAPS / CAPS II e CAPS III do Município de Blumenau / SC**.

## 📚 Estrutura do Curso (5 Módulos Operacionais + Prova Final de 20 Questões)

```
├── Módulo 01: Marco Legal e Filosófico da SRT e o Papel do Cuidador (10Q)
├── Módulo 02: O Cotidiano e o Cuidado Físico com Dignidade (10Q)
├── Módulo 03: Saúde Mental Prática e Manejo de Crises (10Q)
├── Módulo 04: Gestão Segura de Medicamentos na SRT (10Q)
├── Módulo 05: Comunicação e Passagem de Plantão Infalível (10Q)
└── Prova Final Integradora de Conclusão do Curso (20Q)
```

1. **Módulo 1: Marco Legal e Filosófico**
   - Transição do asilo para a moradia na cidade;
   - Estudo de Caso: *"O Retorno à Vida Comunitária de Seu Geraldo"*;
   - Os 3 Eixos de Saraceno (Habitat, Rede Social, Sentido de Vida);
   - Teste de Fixação com 10 questões com gabarito comentado.

2. **Módulo 2: Cotidiano e Cuidado Físico com Dignidade**
   - Construção de rotina flexível (fazer *com* e não *pelo* morador);
   - Banho humanizado e manejo de gatilhos emocionais pós-internação;
   - Ergonomia do cuidador e prevenção de Lesões por Pressão (LPP);
   - Teste de Fixação com 10 questões com gabarito comentado.

3. **Módulo 3: Saúde Mental e Manejo de Crises**
   - Identificação de sinais prodrômicos (insônia, pacing, solilóquios);
   - Técnica dos 10 Princípios de Desescalada Verbal de Richmond;
   - Manejo de crises delirantes e ideação suicida sem punição;
   - Articulação de emergência com CAPS III e SAMU 192 de Blumenau;
   - Teste de Fixação com 10 questões com gabarito comentado.

4. **Módulo 4: Gestão Segura de Medicamentos**
   - Protocolo dos 9 Certos na administração de fármacos;
   - Identificação rápida de reações extrapiramidais (Acatisia, Parkinsonismo, Distonia, SNM);
   - Proibição ética do mascaramento de remédio na comida e conduta na recusa;
   - Teste de Fixação com 10 questões com gabarito comentado.

5. **Módulo 5: Comunicação e Passagem de Plantão**
   - Metodologia internacional **SBAR** (*Situation, Background, Assessment, Recommendation*);
   - Escrita técnica no Livro de Diário de Bordo;
   - Sigilo ético e LGPD na saúde mental;
   - Teste de Fixação com 10 questões com gabarito comentado.

## 📝 Sistema de Avaliação e Testes Didáticos

- **Testes de Fixação Modulares (10 questões por módulo)**:
  - 50 questões de múltipla escolha distribuídas nos 5 módulos.
  - Gabarito comentado detalhado para cada alternativa.
  - Possibilidade de refazer quantas vezes necessário.

- **Prova Final Integradora (20 questões abrangentes)**:
  - Cobre transversalmente leis, ética, manejo de crise, sinais de alerta de suicídio, biossegurança, farmacologia e protocolo SBAR.
  - Critério de aprovação: no mínimo 70% de acertos (14 de 20 questões).
  - Feedback visual imediato com revisão de acertos e erros.

## 🛠️ Simuladores Práticos & Recursos Interativos

- 📋 **Simulador de Passagem de Plantão SBAR**: Escreva a passagem de turno no método SBAR e receba nota de qualidade instantânea com feedbacks educativos.
- 🛡️ **Simulador de Desescalada Verbal em Crises**: Árvore de decisão interativa em tempo real para treino do manejo de surtos sem uso de violência ou contenção física.
- 💊 **Guia de Bolso dos 9 Certos e Efeitos Colaterais**: Consulta rápida de psicotrópicos, sintomas de emergência extrapiramidal e condutas recomendadas.
- 📜 **Compêndio Normativo da Saúde Mental**: Repositório pesquisável das leis e portarias aplicadas ao cotidiano do cuidador.
- 💡 **Widget 'Dica do Dia'**: Frases motivadoras e reflexões diárias sobre o papel do cuidador na Luta Antimanicomial (com botão para copiar).

## 🎓 Cadastro do Aluno & Emissão de Certificado

- **Ficha do Aluno Cadastrado**: Registro de Nome Completo, CPF/Registro Profissional, Cargo/Função, E-mail e Unidade SRT.
- **Certificado Oficial de 40 Horas**:
  - Reconhece a aprovação nos 5 módulos e na Prova Final de 20 questões.
  - Contém código verificador de validação (`SRT-SAL-2026-984`), assinatura das coordenações e formato pronto para impressão A4 / PDF.

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
- **Node.js**: versão 18.0 ou superior
- **npm** ou **yarn**

### Passo a Passo

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/capacita-srt-salomao.git
   cd capacita-srt-salomao
   ```

2. **Instalar as dependências:**
   ```bash
   npm install
   ```

3. **Iniciar o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acessar no navegador:**
   Navegue para `http://localhost:3000` (ou a porta informada pelo terminal).

5. **Gerar a versão de produção (Build):**
   ```bash
   npm run build
   ```

6. **Verificar integridade do código (Lint & Types):**
   ```bash
   npm run lint
   ```

## 📦 Instruções para o Repositório GitHub e Commits

Para enviar o projeto para o seu repositório no GitHub com uma estrutura profissional de commits, siga o passo a passo:

### 1. Inicializar o Git e adicionar os arquivos:
```bash
git init
git add .
```

### 2. Criar o commit principal:
```bash
git commit -m "feat: plataforma Capacita SRT Salomão com 5 módulos didáticos, 10Q por módulo, prova final de 20Q e certificado"
```

### 3. Conectar ao seu repositório remoto no GitHub:
```bash
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/capacita-srt-salomao.git
git push -u origin main
```

### 4. Sugestão de mensagem de commit detalhada:
```text

- Prova Final Integradora de Conclusao com 20 questoes abrangentes e nota de aprovacao

- Gerador de Certificado Oficial de 40 Horas imprimivel
```
